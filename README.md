# Fly-Coop M&B sheet

Mass and balance + navlog + briefing sheet generator (C172 / C152). Fill in the form, then press **Print / save as PDF** (A4 landscape, 2 pages).

Hosted with GitHub Pages: `index.html` is the whole app.

`worker.js` is an optional Cloudflare Worker for reliable NOTAM / METAR / TAF lookup. See the comments at the top of the file.
